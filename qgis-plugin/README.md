# Газрын зураг бэлтгэгч (Numan Map Maker) — QGIS плагин

QGIS төсөлд нээлттэй давхаргуудаас хэвлэлийн газрын зургийг нэг цонхноос автоматаар
угсарч, шууд урьдчилан харж, тохируулж, засварлаж, өндөр нягтралаар экспортлоно.

## Суулгах

1. `numan_map_maker.zip` файлыг татна.
2. QGIS → **Plugins → Manage and Install Plugins… → Install from ZIP** → файлаа сонгоод
   **Install Plugin**.
3. Хэрэгслийн мөрөнд гарах **Газрын зураг бэлтгэгч** товчийг дарна
   (эсвэл **Plugins → Газрын зураг бэлтгэгч**).

QGIS 3.28–3.x хувилбарт зориулсан; QGIS 3.34 LTR дээр туршсан. QGIS 4-т суулгагдахгүй.

## Ашиглах

1. Давхаргуудаа QGIS-т нээж, өнгө загварыг нь тохируулна.
2. Плагиныг нээхэд үндсэн цонхны харагдацаар зураг автоматаар угсрагдана.
3. Зүүн талын табуудаас тохируулна — өөрчлөлт бүр урьдчилан харалтад шууд тусна.
4. Урьдчилан харах талбарт элементийг дарж чирч зөөнө, булангаас нь татаж хэмжээг
   өөрчилнө. **Зургийн агуулга** хэрэгслээр хүрээн доторх газрын зургийг гүйлгэж,
   томруулна. Гараар зөөсөн байрлал тохиргоо өөрчлөхөд хадгалагдана;
   **Байрлал сэргээх** товч автомат байрлалд буцаана.
5. Формат, нягтралаа (dpi) сонгоод **Экспортлох…** дарна.

| Таб | Боломж |
| --- | --- |
| Хуудас | A5–A0 эсвэл дурын хэмжээ, чиглэл, захын зай, фонт, гарчиг, дэд гарчиг, зургийн доорх тайлбар, эх сурвалж |
| Зураг | Хамрах хүрээ (үндсэн цонх / харагдаж буй давхаргууд / сонгосон давхарга), масштаб (авто, дугуйлсан, тогтмол), солбицлын тор (градус-минут-секунд эсвэл метр) |
| Суурь зураг | Фон: Google, OpenStreetMap, Bing, Esri, Mapbox, CARTO-гийн сансрын, topo, hybrid, замын зураг. Overlay: Google labels, Esri зам, хил ба газрын нэр гэх мэт |
| Элемент | Таних тэмдэг, хойд зүгийн сум, масштабын шугам, тоон масштаб |
| Тэмдэг | Таних тэмдгийн нэр, өнгө, дүрсийг засах; ▲ ▼ товчоор дарааллыг солих; чагтаар давхаргыг таних тэмдгээс хасах |
| Хүснэгт | Полигон давхаргын талбайг ангиллаар нь нэгтгэсэн өнгөт хүснэгт (км² / га / м²) |
| Давхцал | Талбайг аймаг, сум, лиценз, ТХГ зэрэг хилтэй (KML, KMZ, GeoJSON, SHP, GPKG) давхцуулж га, хувийг тооцох; өнгөөр ялгасан давхарга, нэрийн бичээс, хүснэгт |
| Фото | Газар дээр авсан фото зургийг байрлуулж, авсан цэг рүү нь шугам татах (GPS солбицлыг EXIF-ээс уншина) |
| Нэмэлт | Байршлын жижиг зураг (улаан хүрээ/цэгтэй), лого, мэдээллийн хүснэгт (гүйцэтгэгч, огноо, проекц, масштаб) |
| Цуврал | Нэг тохиргоогоор олон зураг: объект бүрээр (сум, талбай …) эсвэл давхарга бүрээр; Excel хүснэгттэй хамт |

- **Экспорт:** PNG, JPEG, TIFF, PDF, SVG; 72–1200 dpi; хүсвэл world файлтай.
- **Layout Designer-т нээх:** зургийг төсөлд layout болгон хадгалж, QGIS-ийн
  Layout Designer-т үргэлжлүүлэн нарийвчлан засварлана.
- **Бэлэн загвар:** цонхны дээд талын жагсаалтаас сонгоод «Хэрэглэх». «＋» товчоор одоогийн
  тохиргоог «Миний загвар» болгон хадгална (QGIS-ийн профайлын `numan_map_maker/templates` хавтсанд).
- **Зургийн дугаар:** «Хуудас» табд «Зураг 1.66.» хэлбэрийн дугаарыг автоматаар бичиж, экспорт
  бүрд нэгээр нэмнэ. Гарчиг, тайлбарт `{name}`, `{n}`, `{layer}`, `{date}`, `{project}` бичиж болно.
- **Стандарт загвар:** «Тэмдэг» табын «Стандарт загвар оноох» нь давхаргын нэрээр (гол, зам, хил,
  нуур, ТХГ, түймэр, лиценз …) таньж өнгө, дүрс онооно. «Сонгосныг санд хадгалах…» өөрийн дүрмийг нэмнэ.
- **Хэвлэх:** доод талын «Хэвлэх…» товч зургийг хэвлэгч рүү шууд илгээнэ.
- **Тусламж:** зургийн дээрх «Тусламж» товч товчлуур, таб бүрийн тайлбарыг харуулна.
- **Офлайн суурь зураг:** «Суурь зураг» таб → «Офлайн файл» → OsmAnd-ийн `.sqlitedb` эсвэл `.mbtiles`.
  `.sqlitedb`-г хөрвүүлэхийн өмнө `.mbtiles` файлыг хаана хадгалахыг асууж, дараа нь тэр бэлэн файлыг шууд
  уншина (эх файл өөрчлөгдөхгүй); интернэтгүй ажиллана.
- **Хилийн шугам:** «Давхцал» табын «Хилийн шугам» хэсгээс хилийг зургийн бүх хэсэгт харуулах / нуух,
  өнгө, өргөнийг солих.
- **Хуудасны загвар:** A5, A4, A3 (хэвтээ / босоо), A1 бэлэн загварууд.
- **Том файл:** 1 МБ-аас том KML, KMZ, GeoJSON файлыг «Хилийн файл нэмэх…»-ээр нэмэхэд нэг удаа орон зайн
  индекстэй GeoPackage кэш болгодог (QGIS-ийн профайлын `numan_map_maker/cache` хавтас). Дараа нь зураг зурах,
  давхцал тооцохдоо зөвхөн харагдаж буй хэсгийн объектыг уншина. Эх файл өөрчлөгдвөл кэш шинэчлэгдэнэ.
- **Кэш:** «Нэмэлт» табын доод хэсэгт кэш хавтасны хэмжээг харуулж, «Кэш цэвэрлэх…» товчоор чөлөөлнө
  (одоогийн төсөлд ашиглагдаж буй файл үлдэнэ).
- **Excel:** «Хүснэгт» табын товчоор талбайн хүснэгтийг `.xlsx` / `.csv` болгоно.
- **Загвар хадгалах / ачаалах:** бүх тохиргоог `.json` файлд хадгалж дараагийн зурагт
  дахин ашиглана.

Mapbox-ын зурагт өөрийн access token шаардана («Суурь зураг» табд оруулна). Суурь зураг
интернэт холболт шаардах бөгөөд үйлчилгээ тус бүр өөрийн ашиглалтын нөхцөлтэй.

## Хөгжүүлэгчдэд

- `numan_map_maker/osmand.py` — OsmAnd `.sqlitedb` → MBTiles хөрвүүлэгч.
- `numan_map_maker/fastload.py` — том файлыг индекстэй кэшээр хөнгөн уншуулах.
- `numan_map_maker/overlap.py`, `analysis_ui.py` — давхцлын шинжилгээ; хэвлэх, тусламжийн цонх.
- `numan_map_maker/extras.py` — загварын сан, цуврал, нэмэлт элементийн цонхны хэсэг.
- `numan_map_maker/batch.py`, `templates.py`, `styles.py`, `table_export.py` — цуврал зургийн ажлын
  жагсаалт, бэлэн загвар, давхаргын стандарт загвар, хүснэгт гаргалт (GUI-гүй).
- `numan_map_maker/legend_edit.py` — таних тэмдгийн засвар, KML-ийн загварыг хөрвүүлэх логик.
- `numan_map_maker/basemaps.py` — суурь зураг, overlay-н жагсаалт, төсөлд нэмэх/солих логик.

- `numan_map_maker/composer.py` — тохиргооны толь бичгээс layout угсрах логик (GUI-гүй).
- `numan_map_maker/dialog.py` — цонх, урьдчилан харах, экспорт.
- Zip-ийг дахин үүсгэх: `cd qgis-plugin && zip -r numan_map_maker.zip numan_map_maker -x '*__pycache__*'`
