Sentinel-2 тохиргоо ✕

Sentinel-2 хиймэл дагуулын зургийг харахын тулд өөрийн үнэгүй Sentinel Hub (Copernicus Data Space Ecosystem) Instance ID хэрэгтэй.

1. dataspace.copernicus.eu дээр үнэгүй бүртгүүлнэ
2. Sentinel Hub Dashboard → Configuration Utility → шинэ instance үүсгэнэ (Simple WMS template)
3. Instance ID-г доор оруулна уу

⚠ Энэ тохиргоо зөвхөн одоо ашиглаж буй браузер/төхөөрөмж дээр хадгалагдана (утас ↔ компьютер хооронд автоматаар шилжихгүй). Өөр төхөөрөмж/браузер дээр нэг л удаа дахин оруулна уу.

"TRUE_COLOR" гэдэг нь зөвхөн жишээ нэр — таны Sentinel Hub Configuration дотор яг ямар нэртэй давхарга үүсгэсэн байгаагаас хамаарна. Instance ID-гаа оруулаад "Жагсаалт татах" дарж, өөрийн бодит давхаргуудаас сонгоно уу.

30%

⚠ Sentinel-2 зураг ачаалагдсангүй. Доорх холбоос дээр дарж, Sentinel Hub-аас өгсөн бодит алдааны мессежийг шууд харна уу:

—

Тухайн хуудсанд юу бичигдэнэ (жишээ шалтгаан):
• "Instance ID not found" → ID буруу хуулагдсан эсвэл устгагдсан
• "not authorized" / домэйн тухай зүйл → Sentinel Hub Dashboard дээрх тухайн Configuration-д домэйн хязгаарлалт тавьсан байна (эсвэл file:// зөвшөөрөгдөөгүй)
• Юу ч бичигдэхгүй, хуудас цоо хоосон/ачаалагдахгүй бол → сүлжээ, firewall, эсвэл ad-blocker өргөтгөл sh.dataspace.copernicus.eu домэйныг блоклож байгаа байж болзошгүй (энэ нь desktop дээр илүү элбэг тохиолддог)
